Simple app to extract features from a dataset g40s4 is given in this post.

ui

Thera are three parts in the UI, which are upper part for the chart, lower-left part for the data points, and lower-right part for the i/o triggered by buttons and parameters, as follows.

usage

  • Notice the data in endap-consoles, where each row can be refer with id xxxx.
  • Notice the points with legend (peak, last, linear, model, data) in the chart.
    • peak stands for point of the maximum of y.
    • last stands for point of the last of x.
    • linear stands for initial and final points for liniear regression.
    • model stands for points resulted from linear regression model.
    • data stands for all data points in the dataset.
  • Click load to get default data in the # input.
    • PEAK-ID is id xxxx of point representing peak.
    • LAST-ID is id xxxx of point representing end of the curve.
    • LINI-ID is id xxxs of initial point linear regression.
    • LINF-ID is id xxxs of final point linear regression.
  • Change the id of all point in the # input according to given data points on the lower-left.
  • Make sure that you change the ids accordingly since the given ids are for illustration only.
  • Click read to chek the changes visually, whether they match you expectation.
  • Repeat previous step until you are satisfied with the result.
  • Click calc to perform linear regression.
  • Copy value of peak, last, m, b, R^2, if necessary, to other place for further process.
  • Click clear to clear # input, # output, and also the chart.

notes

  • Initial dataset from 26j27 must be sorted first according to 2nd column.
  • Only two first columns are considered to the dataset used in this post.
