Create, clone, commit, push
A first experience with Git Bash

This story is very basic. Please be patient as you read it.

create account

  • Visit GitHub website https://github.com/ .
  • Find on top most right the Sign up button and click it.
  • Follow the given instruction on https://github.com/signup .
  • Logout to assure you know how to do it.

sign in

  • Visit GitHub website https://github.com/ .
  • Find on top right the Sign in button and click it.
  • Follow the instruction on https://github.com/login .

create repository

  • Sign in to your GitHub account, e.g. dudung.
  • Notice on top of your screen the global navigation menu 1.
  • Find the icon with plus sign + choose New repository as follows.
    • [image-01 on Medium]
  • Fill the repository name, e.g. fisika-di-balik-kopi.
  • Fill (optional) the description, e.g. A talk about coffee and physics in Karawang.
    • [image-02 on Medium]
  • Keep the visibility still Public.
  • Add README by turning it on.
  • Keep without .gitignore or No .gitignore option.
  • Choose license, e.g. MIT License.
    • [image-03 on Medium]
  • Click the green button titled Create repository.
  • Notice that the new repository is created.
    • [image-04 on Medium]
  • It is now available on https://github.com/dudung/fisika-di-balik-kopi .

install git bash

  • Visit Git website https://git-scm.com/install/ .
  • Choose the OS of your choice
    • [image-05 on Medium]
  • Follow the instructions, or other available info 2.

open command prompt

  • On Windows, open File Explorer and navigate to you working folder, e.g. v:\temp.
    • [image-06 on Medium]
  • Using mouse right click and choose Open in Terminal.
    • [image-07 on Medium]
  • On the new window Command Prompt, you can list available files, i.e. type dir and press enter key.
    • [image-08 on Medium]
  • Notice that there is not any files available also.

open git bash

  • In the same folder right click and this time choose Show more options.
    • [image-09 on Medium]
  • Choose Git Bash Here.
    • [image-10 on Medium]
  • On the new window Git Bash (MINGW64), you can list the file, i.e. type ls and press enter key.
    • [image-11 on Medium]
  • Notice that there is not any files available also.

command line interface

Both Command Prompt and Git Bash are CLIs (Command Line Interfaces), but they have different origin and style. The former is Native Microsoft Windows environment, while the latter is Linux / Unix-based emulation (when in Windows).

clone

  • Step into the Git Bash window.
  • Type following command and get the result as follows.
    $ git clone https://github.com/dudung/fisika-di-balik-kopi
Cloning into 'fisika-di-balik-kopi'...
remote: Enumerating objects: 4, done.
remote: Counting objects: 100% (4/4), done.
remote: Compressing objects: 100% (4/4), done.
remote: Total 4 (delta 0), reused 0 (delta 0), pack-reused 0 (from 0)
Receiving objects: 100% (4/4), done.
    • [image-12 on Medium]
  • List again using ls and get the result.
    $ ls -l
total 0
drwxr-xr-x 1 viridi 197121 0 Aug 28 13:12 fisika-di-balik-kopi/

$ ls -l fisika-di-balik-kopi
total 5

-rw-r--r-- 1 viridi 197121   69 Aug 28 13:12 README.md
    • [image-13 on Medium]
  • Compare the result from local storage to the remote one as follows.
    • [image-14 on Medium]
  • Notice they are showing the same files in local and remote storage.

commit

  • On Windows use File Explorer to create .gitignore file.
    • [image-15 on Medium]
    • [image-16 on Medium]
    • [image-17 on Medium]
  • Edit the file to have following content.
    # macOS
.DS_Store
    • [image-18 on Medium]
  • Back to Git Bash and type git status.
    $ cd fisika-di-balik-kopi

$ git status
On branch main
Your branch is up to date with 'origin/main'.

Untracked files:
  (use "git add <file>..." to include in what will be committed)
        .gitignore

nothing added to commit but untracked files present (use "git add" to track)

$ git add .gitignore
    • [image-19 on Medium]
  • Add new file using git add and commit with as follows.
    $ git commit -am "new file"
[main 1807321] new file
 1 file changed, 2 insertions(+)
 create mode 100644 .gitignore

$ git status
On branch main
Your branch is ahead of 'origin/main' by 1 commit.
  (use "git push" to publish your local commits)

nothing to commit, working tree clean
    • [image-20 on Medium]
    • [image-21 on Medium]
  • Notice that there is an published work to the remote store.

push

  • Use git push to upload your local repository commits and internal Git objects to a remote repository, e.g. GitHub.
    $ git push

Counting objects: 100% (4/4), done.

Writing objects: 100% (3/3), 326 bytes | 326.00 KiB/s, done.
Total 3 (delta 0), reused 0 (delta 0), pack-reused 0
To https://github.com/dudung/fisika-di-balik-kopi

  • View the remote files via web browers as follows.
    • [image-23 on Medium]
