A cellular automaton (plural: automata) is a collection of colored cells on a grid of specified shape that evolves through a number of discrete time steps according to a set of rules based on the states of neighboring cells 1. It is a simple model which exhibits fascinatingly complex behavior, where a brief history of it is available 2. There is also online demo about growing neural cellular automata usin WebGL and JS 3. It has many applications 4 and one of them is on gropus 5.

types

There are types of automata such as finite automata, cellular automata, pushdown automata, linear bound automata, and Turing machine 6, where there also other types since there is no single complete list about CA 7.
