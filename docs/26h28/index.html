Information of the course is as follows.

  • code SK5010
  • name Visualization in Science
  • hour 3
  • scopes
    1. History of scientific development and visualization of various scientific phenomena, as well as various software and frameworks, as well as platforms that can be used.
    2. Introduction to various visualization techniques in explaining data, processes, natural phenomena, hypotheses, and other things that cannot be conveyed only by writing and formulas.
    3. Searching for data and creating visualizations uses programming languages, software, frameworks, or online platforms to make it easier to analyze and explain phenomena in the world of science.
    4. Research-based learning is carried out independently by each student based on each student’s choice of topics that have been selected at the beginning of the lecture meeting
    5. Preparation of scientific articles by each student from the results of research-based learning that has been carried out by each student
    6. Presentation of final reports from each student and submission of scientific articles that have been written by each student
  • outcomes
    1. Students are able to analyze data from various phenomena in science using graphic tools and visualization techniques to understand science quantitatively and qualitatively.
    2. Students are able to produce scientific articles that can be submitted to proceedings or journals, both national and international
  • methods Lectures, discussions, research/problem/case study based learning, literature studies, group/independent work, presentations, practice
  • modality Offline/online/hybrid, synchronous and asynchronous
  • grade ABCDE
  • assessment Assessment is given through Homework / Assignments / Quizzes / Practicum / RBL / Reports / Presentations / UTS / UAS
