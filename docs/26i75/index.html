mermaid diagram hands-on

  • Sparisoma Viridi
30 Sep 2026 · 4 mins read · edit

Mermaid diagram is a diagram described entirely in text, where engineers have used Mermaid for years to keep diagrams in their codebase, right next to the code they describe 1. This text-based diagram provides notation that is easly produced by an LLM product, e.g. ChatGPT 4, in summerizing an article 2. Mermaid support flowcharts 3 and mind maps 4, but currently not concept maps 5, where the last can be approached using the first with some limitation.

flowchart

An example of flowchart with on-page connector is as follows 6.

  
flowchart
  %% sg4
  subgraph " "
    direction TB
    o3b --> O1 --> O2 --> E
  end
  
  %% sg3
  subgraph " "
    direction TB
    o2b --> C1
    C1 --"Y"--> P3 --> o4a
    C1 --"N"---> o3a
  end
  
  %% sg2
  subgraph " "
    direction TB
    o1b --> P1 --> P2 --> o2a
    o4b ---> P2
  end
  
  %% sg1
  subgraph " "
    direction TB
    B --> I1 --> I2 --> o1a
  end

  %% elements
  B(["Begin"])
  I1[/"Input 1"/]
  I2[/"Input 2"/]
  P1["Process 1"]
  P2["Process 2"]
  P3["Process 3"]
  C1{"i < n"}
  O1[/"Output 1"/]
  O2[/"Output 2"/]
  E(["End"])
  
  %% connectors
  o1a(("1")):::conn
  o1b(("1")):::conn
  o2a(("2")):::conn
  o2b(("2")):::conn
  o3a(("3")):::conn
  o3b(("3")):::conn
  o4a(("4")):::conn
  o4b(("4")):::conn
  
  %% classes
  classDef conn fill:#484, stroke:#040, color:#fff

concept map

An example of concept map using flowchart is as follows.

  
flowchart
  %% maps
  W --"required by"--> P & H
  P --"produce"--> F
  H --"need"--> F
  F --"can contaminate" --> W

  %% elements
  W(("Water"))
  P{"Plant"}
  F["Food"]
  H(["Human"])

notes

  • There are some steps to correct baseof.html in Hugo to make Mermaid mindmap feature works 7.
  • To browse Font Awesome Icons for Mermaid, please visit https://mermaid.ai/docs/icons/font-awesome . Use it as ::icon(fa fa-paper-plane) after a node.
  • The simplest way to create Mermaid diagram is to use GitHub Issues.
    • Create new repository of your own, e.g. mermaid-hands-on.
    • Create new issue.
      • Example of flowchart is on https://github.com/dudung/26i75/issues/1
      • Example of mind map is on https://github.com/dudung/26i75/issues/2
      • Example of concept map is on https://github.com/dudung/26i75/issues/3
  • To use with endap.js find the update version of 00/template.html , which is still used of CDN instead of local copy of Mermaid 8.
