Usage examples of tensor-1d.js from endap are given in this post, that might be not complete and continued in other post(s).

intro

This moudule is part of endap, where the model term is also new for me 1. For this tensor-1d.js some today included functions, e.g. avg() and sum() will be moved to other module as suggested 2 and currently only len() is supported 3. For multiplication of two 1-d tensor the name mul() is used [^gpt56_luna_2026d]. There is a post preceded this one 4.

code

A usage example is as follows.

import { Tensor1D as T1D } from "endap"

const n = 5;

let a = T1D.create(n);
T1D.fill(a, 1);

let b = T1D.create(n, 2);
let c = T1D.clone(b);
T1D.set(b, 4, -1);

let d = T1D.add(a, b);
let e = T1D.sub(a, b);
let f = T1D.dot(a, b);
let g = T1D.mul(a, b);
let h = T1D.get(b, 4);

let len = T1D.len(c);

console.log(a)
console.log(b)
console.log(c)
console.log(d)
console.log(e)
console.log(f)
console.log(g)
console.log(h)
console.log(len);
