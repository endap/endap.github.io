Four shortcodes for loading and running JS in a Hugo post are given here.

global build

To load a global build JS libraries use following shortcode 1

{{< script/load-plain >}}
abcjs/6.2.3/abcjs-basic-min.js
butiran/0.0.29/butiran.min.js
canvasplot/0.0.0/canvasplot.js
chartjs/4.5.1/chart.umd.min.js
d3/3.5.17/d3.min.js
jquery/4.0.0/jquery.min.js
plotly/3.3.0/plotly-cartesian.min.js
{{< /script/load-plain >}}

where the libraries must be stored under static/js.

esm

To load a JS ES Module use following shortcode 2

{{< script/load-esm >}}
endap
{{< /script/load-esm >}}

where the library is under assets/js with following content

import { Tensor1D } from './core/tensor-1d.js';
import { Console } from './output/consoles.js'
import { RandNum } from './random/numbers.js'

export { Tensor1D, Console, RandNum };

in the index.js as a requirement that imports from other JS files 3.

esm minified bundle

To load the ES Module bundle use following shortcode 4

{{< script/load-esm-min >}}
endap/0.0.5/endap.min.js
{{< /script/load-esm-min >}}

where the libraries must be stored under static/js.

run

To run inline JS code use following shortcode 5:

{{< script/run id="cnt" >}}
/* console */
import { Console as CLI } from "endap"
const consoles = CLI.create("75px");
const cnt = document.getElementById("cnt");
consoles.setTitle("hello-world");
const cli = consoles.el;
cnt.append(cli);


/* output */
consoles.log("Hello, World!");
{{< /script/run >}}

which use a div element as container.

notes

  • This post is created after test for CLI in endap v0.0.5 is successful on 26ja5 .
  • The repo https://github.com/dudung/endap.js is for illustration how to use the minified bundle ES Module and other global builds.
