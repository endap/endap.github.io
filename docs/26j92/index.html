Event browser-executable code written in JS cannot be fully protected 1 but using Vanilla JS to create JSON endpoint is still interesting, since it can keep the JSON structure and JavaScript data-processing logic consistent between the two implementations 2, the simulated API endpoint and the real server endpoint 3. But if the data originates in Excel, remains tabular, and the priority is easy maintenance, it is suggested to use CSV endpoint instead of JSON endpoint 4.
