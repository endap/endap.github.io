Battery - resistor circuit problem will be solved analytically and also numerically using iterative method.

problem

Suppose there is one-loop circuit of a battery $\varepsilon_1$ and resistor $R_1$ as shown in Fig 1.

     R1
+---/\/\/---+
|           |
|           | I
|           | ↓
|    +      |
+----|▮-----+
     ε1

Fig 1. One-loop circuit of a battery $\varepsilon_1$ and resistor $R_1$ with current $I$.

According to Kirchhof’s second law 1 it has relation

$$\tag{1} \varepsilon_1 - V_1 = 0, $$

where

$$\tag{2} V_1 = R_1 I $$

relates $V_1$ to $R_1$ using Ohm’s law 2.

Combine the two equations to have

$$\tag{3} f(I) = \varepsilon_1 - R_1 I, $$

which is the equation to solve for a root $I_r$, that makes $f(I_r) = 0$.

method

A method known as Newton-Raphson method in the form of

$$\tag{4} x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} $$

will be used, where $x \equiv I$. It is a root-finding algorithm that uses the first few terms of the Taylor series of a function $f(x)$ 3.

Notice that the term

$$\tag{5} f'(x) = \frac{df(x)}{dx} $$

is first derivative of $f(x)$ with respect to $x$.

formula

Using the given equation following iterative formula can be obtained

$$\tag{6} I_{n+1} = I_n + \frac{\varepsilon_1 - R_1 I_n}{R_1}, $$

where the root $I_r$ is found when condition $I_n \approx I_{n+1}$ is met.

The analytical solution is simply

$$\tag{7} I = \frac{\varepsilon_1}{R_1}, $$

that will be used as target to achieve.

Notice from Fig 1 that there is err which is a term for numerical error. The iteration stops when absolute difference between $I_{n+1}$ and $I_n$ less than this value.

code

Implemention of previous flowchart is as follows.

import { Console as CLI } from "endap"
const consoles = CLI.create("180px");
const cli = consoles.el;
consoles.setTitle("one-loop batt-rest-circ newton-raphson");

import { Tensor1D as T1D } from "endap"
const n = 100;
const x = T1D.create(n);
const y = T1D.create(n);

const E1 = 10;
const R1 = 20;
const I0 = 1;
const err = 1E-1;
const I = E1 / R1;

function f(x) {
  return E1 - R1 * x;
}

function fx(x) {
  return -R1;
}

function NR(x) {
  return x - f(x) / fx(x);
}

x[0] = I0;
y[0] = f(x[0]);

let m = 0;
for(let i = 0; i < n-1; i++) {
  const dx = -f(x[i]) / fx(x[i]);
  x[i+1] = x[i] + dx;
  y[i+1] = f(x[i+1]);
  const delta = Math.abs(x[i+1] - x[i]);
  m += 1;
  
  if(delta < err) {
    break;
  }
}

consoles.log("n\tI\tf(I)");
for(let i = 0; i < m; i++) {
  const xs = x[i].toFixed(3);
  const ys = y[i].toFixed(3);

  consoles.log(i, "\t");
  consoles.log(xs, "\t");
  consoles.log(ys);
}
consoles.log();
consoles.log("numerical solution");
consoles.log("I = " + x[m]);

consoles.log();

consoles.log("analytical solution");
consoles.log("I = " + I);

closing

One-loop battery-resistor-circuit problem has been solved analytically and also numerically. The first approach is straight forward, while the second requies only one iteration. This approach might be more interesting for number of loops more than one, that will be discussed in other post.
