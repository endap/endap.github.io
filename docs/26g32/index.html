It is a JS library for base functions related to text visualization, e.g. for matrix 26g31 , as suggested 1.

notes

  • In the end of file only new line, e.g. \n (or other OS-dependent characters), is necessary and not visually a new blankline 2.
  • Function name should focus on its function, e.g. create() is preferable over createDiv() 3.
  • Just know that the argument used has special name, tagName 4.
  • Certain CSS options are used to assure style of the displayed texts 5.
  • There is also suggenstion for dom/element.js 6.
  • There are various discussion, e.g. appending element to parent 7, importing IIFE in JS 8, and validation of current code pattern 9.
  • It will be continued in 26g33 as a process in making the app (2d-ca) modular.
