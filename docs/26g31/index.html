It is a JS library for base functions related to matrix.

notes

  • Naming convention for files and functions is as suggested 1. Initial available functions are also planned 2, where some suggested ones are discussed 3.
  • Namespace is preferable over common functions 4 and it is predicted to work using a Hugo shortcode 5, but factory function is avoided for now 6.
  • Two different functions, copy() and clone(), are available 7, but zero() and one() are not 8 due to ambiquity and existence of fill().

functions

Available functions are

  • create(row, col, val=0)
  • identity(dim)
  • fill(mat, val)
  • clone(mat)
  • copy(dst, src)

Include it from core/matrix-2d.js.
