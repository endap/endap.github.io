chartjs learning

  • Sparisoma Viridi
6 Jun 2026 · 2 mins read · edit

Chart.js is a free, open-source JavaScript library for data visualization supporting various chart types including bar, line, area, pie (doughnut), bubble, radar, polar, and scatter 1. It is less flexible and capable than D3, but it is easier to wrap your head around and to get started with 2. It can be used with plain JavaScript or with different module loader 3. With React it is still one of best chart libraries in 2026 4. Version 4.5.1 is published in October last year is the latest 5. Previously, I learnt it by creating a Hugo shortcode 6 and did not grab the knowledge. This time the learning first than implement it in a Hugo shortcode or just using it as inline JS in a note.
