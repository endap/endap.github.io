upper-lower limits 1st-ode

Continuing previous post about a use of ODE 1, which is linear 2, ideas how to set upper and lower limits informed in a dicussion 3 is discussed here. The implementation is for moisture content of coffee bean covered partially with mucilage, where the model should be able to support observation showing two slopes 4, that can be achieved via parameterizing the constants 5.

a limit

Previous equation 1 is modified as follows

$$\tag{1} \frac{d(C - L)}{dt} = -k (C - L) $$

to cover a limit $L$. Equation (1) can be solved with following steps

$$ \begin{align} \nonumber \frac{d(C - L)}{(C - L)} & = -k dt \newline \nonumber \ln (C - L) - \ln (C_0 - L) & = -k (t - t_0) \newline \nonumber \frac{C - L}{C_0 -L} & = e^{-k (t - t_0)} \newline \tag{2} C & = L + (C_0 - L) e^{-k (t - t_0)} \newline \end{align} $$

where at $t = t_0$ it gives $C = C_0$ and at $t = \infty$ it gives $C = L$ instead of $0$. Usually it is chosen that $t_0 = 0$.

The limit $L$ can act as upper limit or lower limit. When $C_0 < L$ then $L$ is upper limit, but when $C_0 > L$ then $L$ is lower limit.
