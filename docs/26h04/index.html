rand-int

  • Sparisoma Viridi
3 Aug 2026 · 1 min read · edit

Generate $n$ random integers $x \in [x_{\min}, x_{\max}]$.

usage

  • Click Default button to load default parameters.
    • NUMX is number of integers.
    • XMIN is minimum integer value.
    • XMAX is maximum integer value.
  • Change the parameters if necessary.
  • Click Generate button to generate random integers using the parameters.

notes

  • Observation on a smartphone, vivo Y28, is generelized to get 320px width 1.
  • Output of this panel can be fed to simple stat 2.
  • Snipped for generating random integer is as follows 3.
    let xi = Math.floor(Math.random() * (xmax - xmin + 1)) + xmin;
