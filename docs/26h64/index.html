sub-itemized text
  • This feature is supported but not recommended to used.
  • Some reasons to discourage the use are
    • reduce the focus,
      • since each point still has sub-points,
      • sometimes sub-points are not related,
    • make more complex,
      • the navigation might be confusing,
      • hierarchy sometimes is unclear
      • mixed use of noun, adjective, etc.
