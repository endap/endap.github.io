common prize as a dream

  • Sparisoma Viridi
5 Oct 2026 · 2 mins read · edit

It takes a while to find the title of this post, which is opposite of a pun 1. The process begins with the term used in gas 2 and apply it to the prize 3, while the announcement of the prize for physics will be tomorrow 4. Since it would be nearly impossible for me to have it, then I define another achieveable prize, Common Prize, where it is achieveable for common people. But, of course, the real one is still a dream to dream of and hopefully none ever read this post. 🤣

dreams

Today, Mon 5 Oct 2026, I set an impossible dreams to achive. First is to have h-index of 100 before retired. Based on current published articles, which is 171 documents 5, it is possible to have the value using the algorithm 6. I still have only a 10th of the target today. Second is to create products, software or hardware, as core of a startup, that implement science and technology developed mostly using local resources. Third is to have the Common Prize as a mile stone toward the Prize. Fourth is to have a new home with small house but large yard for planting and farming, which is an off-grid, green, and sustainable system 7. When there is revision about them, it will be later written here.
