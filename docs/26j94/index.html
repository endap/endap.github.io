large angle pendulum

  • Sparisoma Viridi
21 Oct 2026 · 7 mins read · edit

Name of the problem is vertical circular motion 1, where the common demonstration is a mass bound to a string attached to a fix point 2 and common question is to find minimum speed on the highest position 3. General term might also be applied, a mass on a string, that can also perform horizontal circular motion 4.

This post title evolves from vertical circular motion to large angle pendulum since the last is more fundamental and can be later used for the first.

equations of motion

Following is Newtonian equation of motion of a point mass $m$ under force $\vec{F}$ with $\vec{r}$ is position 5

$$\tag{1} m \frac{d^2 \vec{r}}{dt^2} = \vec{F}, $$

which is not the kinematics equations 6 as long as I know 7.

By choosing $\theta$ as angle between string and vertical direction following expression can be obtained

$$\tag{2} m\omega^2 R = N - mg \cos\theta $$

as centripetal force or sum of forces in radial direction toward to center of rotation 8. Notice that it is a real net force, not like centrifugal force 9.

As long as the mass moves in the circular path with radius $R$ then

$$\tag{3} N \ge 0 $$

and

$$\tag{4} v = \omega R. $$

highest point

Eqn (2) becomes

$$\tag{5} m\omega^2 R = N + mg, $$

at the highest point $H$ where $\theta = \pi$. The it can be rewritten as

$$\tag{6} m\omega^2 R - mg \ge 0 $$

using Eqn (3). Substitute Eqn (4) to Eqn (6) will give

$$\tag{7} v_H \ge \sqrt{gR}, $$

which is the requirement for the mass to move in the circular path without falling at the highest point.

initial position

Using the law of conservation of energy

$$\tag{8} U_L + K_L = U_H + K_H $$

for the kinetic energy $K$ and potensial energy $L$ at lowest point $L$ and highest point $H$ and Eqn (7),

$$\tag{9} \tfrac12 m v_L^2 - mg \ (2R) \ge \tfrac12 m \ (gR) $$

is obtained that gives

$$\tag{10} v_L \ge \sqrt{5gR}. $$

This is the requirement for initial velocity or velocity at the lowest point.

angular direction

There is force in angular direction that has not yet been discussed from Eqn (1), which is

$$\tag{11} mR^2 \frac{d^2 \theta}{dt^2} = - mg \sin \theta \ R. $$

Previous equation can rewritten as

$$\tag{12} \frac{d^2 \theta}{dt^2} = - \frac{g}{R} \sin \theta. $$

characteristic time scale

A characteristic angular frequency in the form of

$$\tag{13} \omega_0 = \sqrt{\frac{g}{R}} $$

is defined, where

$$\tag{14} T_0 = 2\pi \sqrt{\frac{R}{g}} $$

is the corresponding characteristic period. Eqn (14) is usually used as characteristic time scale in numerical solution.

small angle pendulum

For small angle approximation, whose value less than 0.2 rad for absolute difference less than 0.002 between $\theta$ and $\sin \theta$ 10, Eqn (12) simply turns into

$$\tag{15} \ddot{\theta} + \omega_0^2 \theta = 0 $$

with

$$\tag{16} \theta(t) = \theta_0 \cos \omega_0 t $$

as the solution.

large angle pendulum

One way to solve the nonlinear pendulum in Eqn (12) is using numerical Method, e.g. Euler’s method 11, which turns

$$\tag{17} \ddot{\theta} = - \omega_0^2 \sin \theta $$

into

$$\tag{18} \dot{\theta}(t + \Delta t) = \dot{\theta}(t) - \omega_0^2 \sin\theta(t) \Delta t $$

and

$$\tag{19} \theta(t + \Delta t) = \theta(t) + \dot{\theta}(t) \Delta t. $$

Using $\theta_{n+1} \equiv \theta(t + \Delta t)$, $\theta_n \equiv \theta(t)$ and their derivatives, Eqns (18) and (19) can be rewritten in more simple form

$$\tag{20} \omega_{n+1} = \omega_n - \frac{g}{R} \sin \theta_n \Delta t $$

and

$$\tag{21} \theta_{n+1} = \theta_n + \omega_n \Delta t. $$

Eqn (13) is used in Eqn (20) to prevent confusion of $\omega_n$ at $n = 0$ and the characteristic angular frequency.

It is usual to use time step

$$\tag{22} \Delta t = c T_0 $$

where values of 0.01 or 0.001 can be used for $c$.

results

To get $T_0 = 1 \ {\rm s}$ the radius

$$\tag{23} R = g\frac{T_0^2}{4\pi^2} = 9.81 \frac{1^2}{4 \pi^2} \approx 0.248 \ {\rm m} $$

and

$$\tag{24} \frac{g}{R} = \frac{9.81}{0.248} \approx 39.6 \ {\rm s^{-2}} $$

Table 1. Time-related parameters.

Parameter Symbol Value Unit
Characteristic time $T_0$ 1 s
Initial time $t_{\rm beg}$ 0 s
Final time $t_{\rm end}$ 4 s
Time step $\Delta t$ 0.001 s
Observation time $T_{\rm obs}$ 0.1 s

Angular amplitude $\theta_0$ is simply $\pi$, which is not a small angle.

Notice the differences between theoretical (the) and numerical (num) solutions.

code

Following are the code to produce previous results.

/* console */

import { Console as CLI } from "endap"
const consoles = CLI.create("150px");
const cnt = document.getElementById("cnt");
const cli = consoles.el;
cnt.append(cli);


/* params */

const T0 = 1;
const tbeg = 0;
const tend = 4;
const dt = 0.001 * T0;
const Tobs = 0.05 * T0;
const digit = 3;
const g = 9.81;
const R = 0.248;
const A = 0.9 * Math.PI;
const w0 = Math.sqrt(g/R);
const N = (tend - tbeg) / dt;

consoles.log("t\tθ-the\tθ-num");


/* datasets */

const data_the = [];
const data_num = [];

let tobs = 0;
let t = 0;
let w_num = 0;
let q_num = A;
for(let n = 0; n <= N; n++) {
  if(tobs >= Tobs || tobs == 0) {
    const q_the = A * Math.cos(w0 * t);
    const t_str = t.toFixed(digit);
    const q_the_str = q_the.toFixed(digit);
    const q_num_str = q_num.toFixed(digit);
    
    const x = t_str;
    
    const y_the = q_the_str;
    const p_the = {x: x, y: y_the};
    data_the.push(p_the);
    
    const y_num = q_num_str;
    const p_num = {x: x, y: y_num};
    data_num.push(p_num);
    
    consoles.log(t_str, "\t");
    consoles.log(q_the_str, "\t");
    consoles.log(q_num_str);
    tobs = 0;
  }
  w_num += -(g/R) * Math.sin(q_num) * dt;
  q_num += w_num * dt;
  
  t += dt;
  tobs += dt; 
}


/* chart */

const can = document.createElement("canvas");
Object.assign(can.style, {
  width: "100%",
  border: "1px solid var(--muted-border)",
  marginTop: "10px",
});

const config = {
  type: 'scatter',
  
  data: {
    datasets: [
      {
        label: "the",
        data: data_the,
        radius: 4,
        hoverRadius: 6,
        showLine: true,
        /*
        borderColor: "#458",
        backgroundColor: "#8df",
        */
      },
      
      {
        label: "num",
        data: data_num,
        radius: 4,
        hoverRadius: 6,
        showLine: true,
        /*
        borderColor: "#485",

        */
