hassi

  • Sparisoma Viridi
11 Nov 2026 · 1 min read

The name is hassi (hajj affordability and savings simulation initiative) as suggested 1, which means a well (حاسي) in Arabic (Algerian dialect) 2 as confirmed in a source 3.

usage

It is advisable to use HTTP server, e.g. Python’s http.server module 4

python3 -m http.server 8080 -d docs

and display it

       http://localhost:8080

in a browser.

Notice that after editing any files the browser must be refreshed manually to display the recent result.

libs

  • It uses mermaid.min.js v12.3.0 as suggested 5.
