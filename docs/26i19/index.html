This post gives HTML template how to use endap, e.g. endap-console in previous post 1 and also the folder structure 2. It has to be run using local server 3.

folders

Recommended folder structure is as follows.

endap.js/
├── README.md
├── LICENSE
├── libs/
│    ├── abcjs/
│    ├── jquery/
│    ├── plotly/
│    ├── d3/
│    ├── chartj/
│    ├── canvasplot/
│    └── butiran/
├── modules/
│    ├── 01/
│    ├── 02/
│    ├── 03/
│    └── 04/
└── assets/
     └── css/
          └── style.css

You do not have to create the folder manually.

repository

  • Visit endap.js on GitHub [^viridi_2026b] and follow the instructions there.
