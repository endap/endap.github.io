info

Information of the course is as follows.

  • code WI2002
  • name Artificial Intelligence and Data Literacy
  • hour 2
  • scopes
    1. Jenis-jenis data dan metode pengambilan sampel
    2. Exploratory Data Analysis (EDA) dan Statistika Deskriptif
    3. Analisis data univariat dan bivariat (termasuk regresi linier dan koefisien korelasi)
    4. Peluang dan Aturan Bayes
    5. Tata kelola dan etika terhadap data
    6. Definisi Inteligensi Artifisial (IA) dan aplikasi berbasis IA
    7. Level intelligent agent dan jenis machine learning
    8. Tahapan dalan supervised learning
    9. Generative IA Large Language Model (LLM) : teks
    10. Generative IA LLM: non-teks
    11. Etika IA dan Studi Kasus
  • outcomes
    1. Mahasiswa mampu melakukan menjelaskan pentingnya kemampuan literasi data dan Inteligensi Artifisial (IA) yang beretika.
    2. Mahasiswa mampu menjelaskan prosedur pengambilan dan persiapan data yang siap olah.
    3. Mahasiswa mampu mengolah hingga mengambil keputusan berdasarkan data pada fenomena yang sederhana.
    4. Mahasiswa mampu menjelaskan kategori pembelajaran dalam Inteligensi Artifisial (IA).
    5. Mahasiswa mampu mengaplikasikan pendekatan Statistika dan IA pada fenomena-fenomena yang ada di sekitarnya dan relevan terhadap bidang keilmuan masing-masing.
  • methods Ceramah, diskusi kelompok, Pembelajaran kolaboratif, studi kasus, pembelajaran kooperatif
  • modality Bauran, sinkron / asinkron, Mandiri/ Kelompok

  • assessment Kuis, Tugas, Ujian, Tugas besar (kolaboratif)
