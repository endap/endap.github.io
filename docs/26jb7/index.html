Large language models (LLMs) are deep learning models trained on massive text corpora to understand and generate human language and part of generative AI due to their ability in creating new content in the form of text 1. LLMs have made it possible for everyone to interact with an AI – codeless and requires only prompts in natural language 2. Using LLMs well involves extracting value from what they are good at and avoiding wasting time at what they are bad at, since small variations in prompts can make a big difference in the LLM output 3. It is also very important to first acknowledge that LLMs lack genuine awareness or understanding of the tasks assigned to them, because they mimic human responses without truly grasping the underlying purpose of what they are doing 4.

Then comes the term prompt engineering, which is simply the practice of designing and refining the inputs you give to an LLM to get the outputs you want 5. The inputs or LLM prompts are set of instructions you give a language model to guide it to a desired response, and can be anything from a simple question to an input spanning multiple calls 6. Giving contextual prompts will guide the model to focus on a particular area of interest, while constraining responses will limit response length or format that allows for better control over the output 7.

Is it necessary to learn LLM prompting? There is a report about the use of it in automated software engineering through two-phase empirical study covering analysis about 300 papers published at the top-3 SE conferences since 2022 and survey to the 105 program committee members from the conferences 8.

I do use LLMs like Gemini, Claude, but mostly ChatGPT. However, I have never followed a structured learning approach and I have simply learned by doing. This post might the first documented text how I learn it in more structural way

components

The four components of prompt are instruction, context, input and output, whose details are as follows 9.

  • Instruction is a clear directive specifying what the model should or should not do;
  • Context provides additional external information that helps the model generate a more accurate response.
  • Input is the core of the prompt, representing the specific query, question, or data that the user wants the model to address.
  • Output component guides the model on the expected format, style, or type of response, that ensures that the model’s response aligns with the user’s needs and expectations.

framework

A framework known as CO-STAR prompt framework goes a step further than the techniques, which gives distinct and succinct five principles of a prompt guide 14, which are

  • C: Context: Provide background and information on the task,
  • O: Objective: Define the task that you want the LLM to perform,
  • S: Style: Specify the writing style you want the LLM to use,
  • T: Tone: Set the attitude and tone of the response,
  • A: Audience: Identify who the response is for,
  • R: Response: Provide the response format and style.
