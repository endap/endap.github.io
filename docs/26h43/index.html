endap-js shortcode

  • Sparisoma Viridi
16 Aug 2026 · 2 mins read · edit

There are three shortcodes used in developing endap, which are two loaders and one runner, that have been tested 1.

loaders

Third-party libraries are loaded using script/load-plain shortcode as follows.

{{< script/load-plain >}}
abcjs/6.2.3/abcjs-basic-min.js
butiran/0.0.29/butiran.min.js
canvasplot/0.0.0/canvasplot.js
chartjs/4.5.1/chart.umd.min.js
d3/3.5.17/d3.min.js
jquery/4.0.0/jquery.min.js
plotly/3.3.0/plotly-cartesian.min.js
{{< /script/load-plain >}}

Modules from endap are loaded using script/load-esm as follows.

{{< script/load-esm >}}
endap.js
{{< /script/load-esm >}}

In the future there might be other modules beside endap, which are loaded with the same way.

runner

There is only one runner for both endap modules and third-party libraries as follows.

{{< script/run id="cnt" >}}
import { Console as CLI } from "endap"
const consoles = CLI.create();
const cnt = document.getElementById("cnt");
cnt.append(consoles.el);

import { Tensor1D as T1D } from "endap"
const n = 5;
let a = T1D.create(n);
consoles.log(a)

const can = document.createElement("canvas");
Object.assign(can.style, {
  width: "100%",
  border: "1px solid var(--muted-border)",
});
cnt.append(can);

const config = {};
new Chart(can, config);
{{< /script/run >}}

Two first blocks are for ESM modules, while the other blocks are for third-party libraries in plain JS.

html

Hugo generated HTML will have following lines related to the shorcode usage.

<script src="/js/chartjs/4.5.1/chart.umd.min.js" defer></script>
<script type="importmap">
  {
    "imports": {
    "endap": "/js/endap/index.js",
    "endap.js": "/js/endap/index.js"
    }
  }
</script>
<div id="cnt"></div>
<script type="module">
  import { Console as CLI } from "endap"
  const consoles = CLI.create();

  const cnt = document.getElementById("cnt3");
  cnt.append(consoles.el);

  import { Tensor1D as T1D } from "endap"
  const n = 5;
  let a = T1D.create(n);
  T1D.fill(a, 1);

  consoles.log(a);
  
  const config = {};
  cnt.append(can);
  new Chart(can, config);
</script>

Modifications are required to use the HTML in a course. In above output double quotes are added manually since Safari does not show that. Even it works it is still advisable to use double or single quotes 2. It seems due to Hugo minification 3.
