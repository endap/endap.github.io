semi-circle segmented path generator

  • Sparisoma Viridi
4 Oct 2026 · 2 mins read · edit

This a demo for segmented paths visualization, where each path is made of straight line or semi-circle.

usage

  • Click Load button to get the default input.
  • Find the top right textarea, which acts as the input.
  • Modify the input to meet your need.
  • Click Start to perform the path generation according to the input.
  • Fefresh the browser to get clear start.
  • Repeat the initial step, when necessary.

notes

  • There is a pre-print explaining the app and an example of it 1.
  • Original code is available on https://github.com/dudung/butiran.js/blob/master/app/scspg/scspg.js [20261004].
  • One of the modifications is to change all var to let and add missing let to asssure the scope 2 and change the implementation using with(), which is forbidden in in JS strict mode 3.
  • Since Clear button has not been implemented yet, browser refrech button ↻ is used instead.
