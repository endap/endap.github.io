mermaid-12.3.0 setup

  • Sparisoma Viridi
12 Nov 2026 · 2 mins read

Presented here the change of mermaid setup from v10.9.8 using CDN 1 to v12.3.0 using local JS library as suggested 2 for a post generted using Hugo 3. The file named basedof.html, which is the base template 4, must be modified. Modified and original files are given here.

template

The file baseof.html that is stored in layout/_default folder, has following modifed part for Mermaid.

{{ if .HasShortcode "mermaid" }}
<script src="/js/mermaid/12.3.0/mermaid.min.js"></script>
<script>

  const dark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    
  mermaid.initialize({
    startOnLoad: false,
    theme: dark ? 'dark' : 'default',
    themeVariables: {
      fontSize: "20px",
      nodeFontSize: "18px",
      labelFontSize: "14px",
      edgeLabelBackground: 'transparent',
      lineColor: dark ? '#aaa' : '#333'
    },
    themeCSS: `
      .edgeLabel, .edgeLabel p, .labelBkg { background-color: var(--bg) !important; }
      .edgeLabel rect { fill: transparent !important; opacity: 0 !important; }
      .flowchart-link, .edge-thickness-normal { stroke-width: 1px !important; }
    `
  });
  
  document.addEventListener("DOMContentLoaded", async () => {
    await mermaid.run({
      querySelector: ".mermaid"
    });
  });
</script>
{{ end }}

There are also changes related to dark theme styling 5. Original version of the base template has following part for Mermaid.

{{ if .HasShortcode "mermaid" }}
<script type="module">
  import mermaid from "https://cdn.jsdelivr.net/npm/mermaid@10.9.8/dist/mermaid.esm.min.mjs";

  mermaid.initialize({
    startOnLoad: false,
    theme: "neutral",
    themeVariables: {
      fontSize: "20px",
      nodeFontSize: "18px",
      labelFontSize: "14px"
    }
  });
  
  document.addEventListener("DOMContentLoaded", async () => {
    await mermaid.run({
      querySelector: ".mermaid"
    });
  });
</script>
{{ end }}

Notice that the template that uses CDN requires internet connection, but other does not.
