apparatus-sketch js-svg

  • Sparisoma Viridi
5 Nov 2026 · 2 mins read

To draw objects in webpage we can use Canvas or SVG, where the last is ideal for highly interactive, responsive, and accessible visualizations 1. It also provides to add dan remove node dynamically using pure JavaScript 2. In this post the approach will be use for drawing apparatus sketch 3. In SVG em, ex, px, pt, pc, cm, mm, in, and percentages are the supported length unit identifiers 4. It is adviseable to use only px for drawing 5. It is also better use SVG only in rendering of a JS object for reusability 6.

examples

A simple example is as follows.

const cnt = document.getElementById("cnt1");

const svg = document.createElementNS('http://www.w3.org/2000/svg','svg');
svg.setAttribute('width','200');
svg.setAttribute('height','200');
svg.setAttribute('style','border: 1px solid var(--border);');
svg.setAttribute('viewBox','-20 0 180 200');

const rect = document.createElementNS('http://www.w3.org/2000/svg','rect');
rect.setAttribute('stroke','var(--fg)');
rect.setAttribute('fill','none');
rect.setAttribute('width','100');
rect.setAttribute('height','120');
rect.setAttribute('x','20');
rect.setAttribute('y','10');

cnt.append(svg);
  svg.append(rect);

Notice that the SVG use viewBox that translate the top left cornder to (-20, 0) from its default value (0, 0).
