hugo draft not to render

  • Sparisoma Viridi
25 Sep 2026 · 2 mins read · edit

Currently in front matter I set draft = true by default in post template default.md stored in archetypes folder 1, that prevents Hugo from including the post when it builds or serves the site, unless the option --buildDrafts is passed on the CLI 2. But when there is no draft parameter at all in the front matter, it does not consider the post as draft and another approach via hugo.toml is required 3.

The problem to fix is most of the posts are with draft = false but I want to change many of them to true without editing many posts. Is there a way to do that using the most efficient way? That’s what this post all about. A warm discussion 4 leads to the use of ignoreFiles in the hugo.toml file 5, which can prevent all files in certain folder to be built and then work on them one by one to set the right value of draft parameter in the front matter. It has been tested for /content/index and it works fine.
