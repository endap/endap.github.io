new hugo archetypes

  • Sparisoma Viridi
31 Oct 2026 · 3 mins read · edit

To create a new certain type of content in Hugo, e.g. post, page, section, etc, a recommended way is using archetypes that will provide it with pre-filled metadata and markup 1. The pre-filled metadata is stored as custom fields in the front matter of each post, which are beyond standard fields like title and date, that can also incorporate custom fields and implement conditionals 2. Front matter can be TOML, YAML, or JSON and markup is typicallyy Markdown 3.

new

Current default.md is as follows.

{{- $words := split .Name "-" -}}
{{- $title := delimit (after 1 $words) " " -}}

{{- $filepath := path.Clean .File.Path -}}
{{- $parts := split $filepath "/" -}}
{{- $file := index (last 1 $parts) 0 -}}
{{- $parts1 := first 2 (after 1 $parts) -}}
{{- $parts2 := first 1 (split $file "-") -}}
{{- $surl := $parts1 | append $parts2 -}}
{{- $url := delimit $surl "" -}}

{{- $hhmm := (time .Date).Format "1504" -}}
{{- $year := index (split (time .Date) "-") 0 -}}
{{- $yyyymmdd := (time .Date).Format "20060102" -}}
{{- $ddmmyyyy := (time.AsTime .Date).Format "2 Jan 2006"  -}}
{{- $file2 := index (split $file ".") 0 -}}


+++
title = '{{ $title }}'
date = '{{ .Date }}'
authors = ['viridi']
draft = true
type = 'notes'
tags = []
categories = []
math = false
url = '{{ $url }}'
+++

<!-- more -->


`01-{{- $hhmm -}}` this day begins with `{{ $file2 }}` as intial docs and the entries can be in `en`, `id`, `de`, or `xx` when necessary.
