combine 4-datasets to cols

  • Sparisoma Viridi
4 Aug 2026 · 1 min read · edit

Combine four one-column datasets to single four-column dataset.

usage

  • Click Clear button to clear all textareas.
  • Fill upper textareas with semicolon-separated value.
  • Click Combine button to combine datasets in upper textareas and show the result in lower textarea.
  • Use other panels output as inputs, e.g. 26h04 for col-1, 26h04 for col-2, 26h04 for col-3, 26h06 for col-4 (upper part).
  • Use output as input for other panel, e.g. 26b56 from col-5 (lower part).

notes

  • Combining multiple datasets is supported via pandas in Python 1, already common in Excel 2, and using merge() function in R 3.
  • This panel can get input from, e.g. other panels 45 and forward the output to, e.g. other panel 6.
