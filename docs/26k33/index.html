sign function flowchart

  • Sparisoma Viridi
12 Nov 2026 · 2 mins read

Sign function 1 is already common written in the form of piecewise function 2. A flowchart 3 can also be used to illustrate how the function work. In this post flowchart representing the function is given accompanied with code and the result.

function

Function representation of sign function using piecewise function is as follows.

$$\tag{1} \textrm{sign}(x) = \left\{ \begin{matrix} -1, & x < 0, \newline 0, & x = 0, \newline +1, & x > 0. \end{matrix} \right. $$

It is uncommon to write +1 for 1.

flowchart

Eqn (1) can also be illustrated in the form of a flowchart as follows.

Fig 1. Flowchart of sign function.

Two conditional elements are required since one conditional element can only provide two different output condition.

result

Suppose there are numbers -2, -1, 0, 1, 2, where their sign are as follows.

Notice that the result can produce +1 instead of only 1.

code

Previous result is obtained using following code.

function sign(x) {
  return x < 0 ? "-1" : (x == 0 ? "0" : "+1");
}

const min = -2;
const max = 2;
for(let i = min; i <= max; i++) {
  const s = sign(i);
  consoles.log("sign(" + i + ") = " + s);
}

To assure that the function sign(x) can produce +1, it returns string instead of integer.

notes

  • Flowchart representation of a function might be not unique.
  • There are actually other variations of conditions that still give the correct results.
