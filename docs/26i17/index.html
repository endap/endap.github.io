It is the first tutorial how to use endap consoles.log() that mimics JS console.log() as previously reported while developing it 1.

hello world

How to show “Hello, World!” is as follows.

Following is the code

import { Console as CLI } from "endap"
const consoles = CLI.create("40px");

const cnt = document.getElementById("cnt1");
cnt.append(consoles.el);

consoles.log("Hello, World!");

to get previous result.

version

How to show version of endap-consoles is as follows.

Following is the code

import { Console as CLI } from "endap"
const consoles = CLI.create("30px");

const cnt = document.getElementById("cnt2");
cnt.append(consoles.el);

consoles.ver();

to get previous result.

for

Following example show how to produce number using for()

where the code is as follows.

import { Console as CLI } from "endap"
const consoles = CLI.create("100px");

const cnt = document.getElementById("cnt3");
cnt.append(consoles.el);

for(let i = 0; i < 5; i++) {
  consoles.log(i);
}

Compare previous result with following one.

where

for(let i = 0; i < 5; i++) {
  consoles.log(i, ",");
}

is the only modified lines.

chars triangle

Notice following output.

that is produces using

import { Console as CLI } from "endap"

How about this one?

The code is as follows.

import { Console as CLI } from "endap"
const consoles = CLI.create("100px");

const cnt = document.getElementById("cnt6");
cnt.append(consoles.el);

for(let i = 1; i <= 5; i++) {
  for(let j = 1; j <= 5-i; j++) {
    consoles.log(" ", "");
  }
  for(let j = 1; j <= i; j++) {
    consoles.log("o", "");
  }
  consoles.log();
}

misc

Suppose there are values whose quadrat and cube must be calculated as follows.

Use following code

import { Console as CLI } from "endap"
const consoles = CLI.create("140px");

const cnt = document.getElementById("cnt7");
cnt.append(consoles.el);

consoles.log("x\tx^2\tx^3");
for(let x = 0; x < 6; x++) {
  let x2 = x * x;
  let x3 = x * x2;
  consoles.log(x, "\t");
  consoles.log(x2, "\t");
  consoles.log(x3);
}

to get the result.
