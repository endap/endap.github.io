A cellular automaton is a collection of “colored” cells on a grid of specified shape that evolves through a number of discrete time steps according to a set of rules based on the states of neighboring cells, where the rules are then applied iteratively for as many time steps as desired 1. The mark of CA is in their displaying complex emergent behavior, starting from simple atoms following simple local rules, that attracts a growing number of researchers from the cognitive and natural sciences willing to study pattern formation and complexity in a pure, abstract setting 2. Researchers are showing their interest in the field of Cellular Automata based efficient hardware and software applications with the range of available literature and methodology 3. Here trials of simple algorithm are documented, which using previous viewer 4.

example

Simple example of ca is as follows.

Fig 1. Spread of cells using average and round function with 3×3

It is simply taking avarage of neighbor cells and get integer value less than it

$$\tag{1} m_{ij}^{t+1} = \frac{1}{9} \left\lfloor \sum_{a = i-1}^{i+1} \sum_{b = j-1}^{j+1} m_{ab}^t \right\rfloor, $$

where there are slightly modification when row and col at the edge of the matrix, which is similar to forward and backward in FDM.

discussion

  • It seems that values of cells does not correspond linearly with colors. Currently, for simplicity, cells values are simple [0, 255] as the color in hexadecimal.
  • For t = 7,
    • middle row has values [4, 4, 11, 32, 73, 255, 73, 32, 12, 7, 12],
    • bottom row has values [1, 1, 3, 7, 11, 12, 11, 7, 3, 2, 3].
  • Color value less than 73 is not sensible, e.g. bottom row does have values, but it can not be seen in Fig 1.
