gh-pages creation-steps

  • Sparisoma Viridi
8 Oct 2026 · 3 mins read · edit

It is shorter, more simpler, and updated version of previous story about how to create a simple website on GitHub Pages 1 and also the more complex one with multipe pages 2.

notes

  • 01 Notice that GitHub username dudung and repository name my-website are just for example.
  • 02 Change dudung to your username, e.g. username.
  • 03 Change fi2151-web to repository name you want to have, e.g. my-website.

create new repository

  • 01 Visit your GitHub user page, e.g. https://github.com/dudung/ .
  • 02 Find at top rather left a button with + symbol.
  • 03 Click the + button and choose New repository.
  • 04 Fill Repository name, e.g. fi2151-web
  • 05 Fill Description, e.g. an example of gh-pages.
  • 06 Choose visibility to Public.
  • 07 Turn on Add README.
  • 08 Skip Add .gitignore.
  • 09 Add license to MIT License.
  • 10 Click green button below with caption Create repository.

create landing page

  • 01 Visit the repository if not forwarded automatically, e.g. https://github.com/dudung/fi2151-web .
  • 02 Find + button near the green button <> Code.
  • 03 Click the button and choose + Create new file.
  • 04 Type docs then index.html.
  • 05 Move cursor to textarea below.
  • 06 Type the content as follows. 
    <html>
  <head>
    <title>gh-pages for fi2151</title>
  </head>
  <body>
    <h1>home</h1>
    <p>Hello, World!</p>
  </body>
</html>
  • 07 Click Commit changes…, the green button on the top right.
  • 08 On the pop-up, click Commit changes on the bottom right, the green button.
  • 09 Check the index.html exists, e.g. https://github.com/dudung/fi2151-web/blob/main/docs/index.html .

set github pages

  • 01 Go to main page of your repository, e.g. https://github.com/dudung/fi2151-web .
  • 02 Find Settings on the rather top left of the screen.
  • 03 Find Pages on the left sidebar menu.
  • 04 Keep Source to Deploy from a branch.
  • 05 Under Branch change None to main.
  • 06 Change / (root) to docs.
  • 07 Click Save.

set repo page

  • 01 Go to main page of your repository, e.g. https://github.com/dudung/fi2151-web .
  • 02 Wait until the orange circle indicator turns into green check mark.
  • 03 Click ⚙ on the left of About.
  • 04 Under Website, check Use your GitHub Pages website.
  • 05 Under Include in the home page, uncheck all.
  • 06 Click Save changes, a green button on the bottom right.

view the web.

  • 01 Go to main page of your repository if not still there, e.g. https://github.com/dudung/fi2151-web .
  • 02 Find Under Above your website address, e.g. https://dudung.github.io/fi2151-web/ .
  • 03 Click the link.
  • 04 The web page https://dudung.github.io/fi2151-web/ should be shown.
