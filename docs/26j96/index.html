uniform circular motion

  • Sparisoma Viridi
21 Oct 2026 · 5 mins read · edit

Motion of an object in a circle at a constant speed is known as uniform circular motion 1. During the motion distance of the object from a center is always the same, velocity is always perpendicular to the circular trajectory, and acceleration is always toward to the center 2. Applying Newton’s second law of motion to a charged particle moving perpendicular to a constant homogenous magnetic field gives the solution of a circular trajectory 3. Unfortunatey, acceleration sensor on Android-based smartphone attahed to a moving train toy in a circle can not give clear measurement of the centripetal force 4.

parametric equations

A circle can be represented using parametric equations 5

$$\tag{1} x(t) = x_c + R \cos (\omega t + \phi_0) $$

and

$$\tag{2} y(t) = y_c + R \sin (\omega t + \phi_0), $$

where center of the circle is $(x_c, y_c)$, circle radius is $R$, angular velocity of the circular motion is $\omega$, and initial phase of the motions is $\phi_0$. Eqns (1) and (2) show position of a particle moving in a circle.

Velocities can be obtained by deriving Eqns (1) and (2) with respect to time $t$ that gives

$$\tag{3} v_x(t) = -\omega R \sin (\omega t + \phi_0) $$

and

$$\tag{4} v_y(t) = \omega R \cos (\omega t + \phi_0). $$

Further derivation will give the accelerations

$$\tag{5} a_x(t) = -\omega^2 R \cos (\omega t + \phi_0) = -\omega^2 [ x(t) - x_c ] $$

and

$$\tag{6} a_y(t) = -\omega^2 R \sin (\omega t + \phi_0) = -\omega^2 [ y(t) - y_c ]. $$

Notice the relation between Eqns (5) and (6) with Eqns (1) and (2)

initial conditions

At $t = 0$ initial positions are given by Eqns (1) and (2), which are

$$\tag{7} x_0 = x_c + R \cos \phi_0 $$

and

$$\tag{8} y_0 = y_c + R \sin \phi_0. $$

Alternatively following relation

$$\tag{9} \tan \phi_0 = \frac{y_0 - y_c}{x_0 - x_c} $$

can be obtained.

Initial velocities are given by Eqns (3) and (4), which are

$$\tag{10} v_{0x} = -\omega R \sin \phi_0 $$

and

$$\tag{11} v_{0y} = \omega R \cos \phi_0. $$

Similar to Eqn (9) following relation

$$\tag{12} \tan \phi_0 = - \frac{v_{0x}}{v_{0y}} $$

can be obtained.

period

The time for one of a uniform circular motion is period $T$ 6, which is related to anggular velocity $\omega$ via

$$\tag{13} \omega = \frac{2\pi}{T}. $$

result

If the period is 2 s then the angular velocity is π rad/s. Circle center is $(2, 3)$, radius is $0.5$ m, and initial phase $\tfrac12 \pi$.

code

Previous result is obtained using following code.

/* console */

import { Console as CLI } from "endap"
const consoles = CLI.create("150px");
const cnt = document.getElementById("cnt");
const cli = consoles.el;
cnt.append(cli);


/* params */

const T = 2;
const tbeg = 0;
const tend = 4;
const dt = 0.001 * T;
const Tobs = 0.01 * T;
const digit = 3;
const N = (tend - tbeg) / dt;

const xc = 2;
const yc = 3;
const R = 0.5;
const w = 2 * Math.PI / T;
const phi0 = Math.PI / 2;


/* datasets */

const data = [];

let tobs = Tobs;
let t = 0;
for(let n = 0; n <= N; n++) {
  if(tobs >= Tobs) {
    
    const x = xc + R * Math.cos(w * t + phi0);
    const y = yc + R * Math.sin(w * t + phi0);
    
    const ts = t.toFixed(digit);
    const xs = x.toFixed(digit);
    const ys = y.toFixed(digit);
    const p = {x: xs, y: ys};
    data.push(p);
    
    consoles.log(ts, "\t");
    consoles.log(xs, "\t");
    consoles.log(ys);
    tobs = 0;
  }
  
  t += dt;
  tobs += dt; 
}


/* chart */

const can = document.createElement("canvas");
Object.assign(can.style, {
  width: "100%",
  border: "1px solid var(--muted-border)",
  marginTop: "10px",
});

const config = {
  type: 'scatter',
  
  data: {
    datasets: [
      {
        label: "data",
        data: data,
        radius: 4,
        hoverRadius: 6,
        showLine: true,
      },
      {
        label: "center",
        data: [
          {
            x: xc,
            y: yc,
          }
        ],
        radius: 4,
        hoverRadius: 6,
        showLine: true,
      },
    ],
  },

  options: {
    
    maintainAspectRatio: true,
    aspectRatio: 1,
    
    scales: {
      x: {
        type: 'linear',
        title: {
          display: true,
          text: 't',
          font: { size: 14, },
        },
      },

      y: {
        type: 'linear',
        title: {
          display: true,
          text: 'θ',
          font: { size: 14, },
        },
      },

    },
  },

};
