This post is an attempt to find info about muon detection technology, the muon tomography or muography 1 and related aspects.

apps

  • archeology 2,
  • volcanology 3,
  • civil structures 4,
  • small object imaging 5,
  • cargo detection 6,
  • human anatomy monitoring 7.

imaging

  • Using natural muons require much longer time compared to artificial muons in having the muography 8.
  • There is a report about the first demonstration of imaging dominated by an artificial, laser-driven muon beam, where the images were created almost entirely by muons 9.
  • Monte Carlo simulation usually is used to perform the imaging, a combined analysis of muon scattering and absorption data 6.

diy

  • There is a USD 100 muon detector using two Geiger-Müller tubes and an Arduino Nano microcontroller10.
  • The Desktop Muon Detector(v3X) is another a USD muon detector 11.
