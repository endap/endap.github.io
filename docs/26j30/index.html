To perform software development using agent, LLM prompting, or related technologies, where I am not sure, which one is which, at least there are some reported techniques, platforms, tools, and languages and frameworks, whose poitions are still dynamics, that can be in adopt, trial, assess, or caution category 1. Later, I was informed about spec-driven development (SDD), where event in last year definition of the term is still in flux 2 and understanding exactly what it is is difficult 3. This approach differs from TDD (test-driven development), BDD (behavior-driven development), and Vibe Coding 4. There is alo ATDD (acceptance test-driven development), DDD (domain-driven design) and FDD (feature-driven development) 5.

Spec-driven development is a contract how the code should behave and it becomes the source of truth the tools and AI agents use to generate, test, and validate, so that the result requires less guesswork, produces fewer surprises, and has higher-quality [delimarsky_2025]. Development team defines guardrails, requirements, constraints, acceptance criteria, and edge cases up front, then use AI to generate code, tests, and supporting artifacts from that shared context 6. It inverts the traditional workflow by treating specifications as the source of truth and code as a generated or verified secondary artifact 7.
