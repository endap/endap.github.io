An example how to use CLI in endap v0.0.5 is given in this post.

output

Following is an example of the emulated CLI.

A div element is used as output element.

code

Following is the code to produce previous result.

/* console */
import { Console as CLI } from "endap"
const consoles = CLI.create("75px");
const cnt = document.getElementById("cnt");
consoles.setTitle("hello-world");
const cli = consoles.el;
cnt.append(cli);


/* output */
consoles.log("?");
consoles.clear();
const n = 10;
for(let i = 0; i < n; i++) {
  consoles.log(i, ", ");
}
consoles.log();
consoles.ver();
consoles.log("Hello, World!");

Notice that the log("?") does not show the character due to the use of clear() after it.
