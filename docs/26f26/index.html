A matrix storing only 0 and 1 numbers can be used to show a binary image 1 as follows

which is using previous code 2. Notice that binary image is not a duotone image 3, and the binary image is also refered as monotone image 4.

colors

Let us design four colors as follows 5

colors = ["#00f", "#33c", "#639", "#936", "#f00"];

where the matrix simply has only values of 0-4.

container

A div is used as container for canvas and another div elements, where they are used for drawing and displaying text.

Fig 1. Three boards are used in showing the system at t = 1, 2, 3, 4 of a cooling process.

Problem of vertical space between canvas and its container is solved by using display: block, as suggested in order to override display: inline, default value 6.

function

A function is defined as follows

function createBoard(mat, colors, text) {
  const rnum = mat.length;
  const cnum = mat[0].length;
  const gsize = 20;
  const width = cnum * gsize;
  const height = rnum * gsize;
  
  const can = document.createElement("canvas");
  can.width = width;
  can.height = height;
  can.style.width = width + "px";
  can.style.height = height + "px";
  can.style.display = "block";
    
  const board = document.createElement("div");
  board.style.border = "0px solid yellow";
  board.style.width = "fit-content";
  board.style.height = "auto";
  board.style.display = "inline-block";
  board.style.marginRight = "4px";
    
  const title = document.createElement("div");
  title.style.width = "100%";
  title.style.paddingLeft = "0.2em";
  title.innerHTML = text;
  
  const ctx = can.getContext("2d");
  let j = 0;
  for(let r of mat) {
    let i = 0;
    for(let c of r) {
      const x = i * gsize;
      const y = j * gsize;
      ctx.fillStyle = colors[c];
      ctx.fillRect(x, y, gsize-1, gsize-1);
      ctx.fill();
      i++;
    }
    j++;
  }
  
  board.append(title);
  board.append(can);
  
  return board;
}

for creating a board, which is simply a div element as container for div and canvas elements.
