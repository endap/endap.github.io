get familiar with workbench 2026-r1

  • Sparisoma Viridi
30 Sep 2026 · 2 mins read · edit

After installation name of the application to launch is Workbench 2026 R1 1.

open-close

  • Press Window key ⊞ and type workbench and press enter.
  • Wait until Ansys 2026 R1 fully run.
  • Notice that the window title is Unsaved Project - Workbench.
  • Press Ctrl+Q to close the window.

geometri apps

Workbench 2026 R1 provides three geomtery editors, which are DesignModeler, SpaceClaim, and Discovery. There is suggestion to choose SpaceClaim over DesignModeler 1, but the other suggest to use Discovery due to unavailabily of SpaceClaim for installation starting in 2007 2 and also because Discovery is beginner friendly 3.

In the Workbench 2026 R1 the default geometry editors is Discovery and it might be better to keep it.

strain-stress curve

The steps are as follows 4.

  1. Open ANSYS Workbench → add Static Structural analysis.
  2. Under Geometry, right-click → Import Geometry → select the IGES (.igs/.iges) file.
  3. Open the geometry in SpaceClaim/DesignModeler and check/repair the geometry if necessary.
  4. In Engineering Data, define the material properties, especially Young’s modulus, Poisson’s ratio, and yield/plastic data if nonlinear analysis is required.
  5. Open Mechanical and define:
    • Mesh
    • Boundary conditions/supports
    • Applied force or displacement
  6. Solve the analysis.
  7. Insert Equivalent (von-Mises) Stress and Equivalent Elastic Strain results.
  8. To obtain the stress–strain curve, create a Chart/Probe or export the stress and strain results to a spreadsheet and plot Stress vs. Strain.

notes

  • The executable is RunWB2.exe in C:\Program Files\ANSYS Inc\ANSYS Student\v261\Framework\bin\Win64 folder.
