Usage examples of consoles.js from endap is given in this post. It migh be not the final version. Updates will be in another post(s).

intro

This module is to simulate native console.log() so that the output can be displayed in HTML without showing JavaScrip Console, where it has not been used in previous module 1. For a little bit playful the name is consoles which similar to console 2 and it will use div element 3.

results

The results are as follows.

code

Previous results are obtained using following lines of code

import { Console as CLI } from "endap"
const consoles = CLI.create();

const cnt = document.getElementById("cnt");
cnt.append(consoles.el);

consoles.log("Hello, World!");

const x = [9, 6, 5];
consoles.log(x);

for(const i of x) {
  consoles.log(i, ",");
}
consoles.log();

const r = {
  x : 1,
  y: 2,
  z: "n/a",
};
consoles.log(r);

const y = 7.25
consoles.log("y = " + y);

Only lines after cnp.append() are contributed to the given output.
