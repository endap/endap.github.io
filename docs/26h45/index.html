endap-js console hello world

Due to some advantages of CLI over GUI 1 and opinion about it 2, this post introduces an emulator of it from endap. And, as you guess, the example is simply a “Hello World” program 3.

code

Several lines are still required to display “Hello, World!”.

import { Console as CLI } from "endap"
const consoles = CLI.create("20px");
const cnt = document.getElementById("cnt");
cnt.append(consoles.el);
consoles.log("Hello, World!");

First four lines in the code are for preparing the interface to display “Hello, World!” in a div element, emulating a CLI. Height of the div element is 20px in the example.
