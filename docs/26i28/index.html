m-fender deflect-test-data

  • Sparisoma Viridi
13 Sep 2026 · 3 mins read · edit

Available deflection test sheets are a little bit confusing since one has three pleriminary compression and one main compression, the other three have only one preliminary compression, and two of the threee are just copied, then an interpretation is made based on a discussion 1, which will be later confirmed in next monday meeting. All of them has reaction force and absorption energy in the form of table and chart. Since the test is a fender level performance test there is an requirement to request material level test and add it to software material library 2. There is also note about the measurement units between the tests and the simulations 3. If there is not any plan change the data will be used in the prepared simulation system 4. Currently the available compression stress-strain test data is sufficient 5.

info

  • Dataset name pnsm is for product batch n and sample m.
  • Test has begin time (tbeg) and end time (tend).
  • Test has start temperature (tsta) and finish temperature (tfin) in °C.
  • Deflection (def) is in mm and %.
  • Reaction force (Frea) is in tf (ton-force), which equals to 9.80665 kN.
  • Absorption energy (Eabs) is in tf·m (ton-force·m), which equals to 9.80665 kJ.
  • All rubbers are Grade A.
  • Chart Frea (0:140:2) vs def (10:50:10).
