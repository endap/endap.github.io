  • Sparisoma Viridi

It is a post with suggested title 1 showing how to use a Hugo shortcode nemed panel-v0.a 2. Limitation of a file-based presentation might be overcome with a blog-based presentation 3. Information of 2026-1 semester 4 will be used as the case.

launch button

To enter the slide show mode shortcode named button is used as follows.

<!-- launch button -->
{{< panel/v0a/button target="p01" label="slide show" >}}

that produces

slide show

a clickable link for launching the presentation. Notice that p01 is id of the first panel, usuallay shortcode named title.

initialization

Style used in the panels is loaded via a shorcode named style which is used as follows

<!-- panel initialization -->
{{< panel/v0a/style >}}

that does not give immediate visible effect.

info and title

Title slide is displayed using shortcode namef info than followd by shortcode named title as follows

<!-- p01 -->
{{< panel/v0a/info
  authors="Sparisoma Viridi"
  footnotes="endap/26h60|2026-08-23|1p"
  version="20260823_v0"
  url="https://endap.github.io/26h60/"
>}}

{{< panel/v0a/title id="p01" next="p02" page="1" >}}
# 2026-1 semester info with panel shortcode
## a panel-v0.a usage
{{< /panel/v0a/title >}}

^

content

A commont shortcode named content is used to display bulleted entries, where it is used as follows.

{{< panel/v0a/content id="p02" prev="p01" next="p03" page="2" >}}
## outline
+ courses &middot;&middot;&middot; 3
+ closing &middot;&middot;&middot; 6
{{< /panel/v0a/content >}}

^

  • closing ··· 6
