viewing spring-mass-system using 3dmoljs

  • Sparisoma Viridi
17 Nov 2026 · 2 mins read

For a CNT-like structure there are terms suggested 1. This structure will be visualized using 3Dmol.js via its API 2.

particles

To form a HCP cylinderical structure some parameters are related 3

$$\tag{1} d_p = d_r \sin \left( \frac{\pi}{n_r} \right), $$

where $d_p$, $d_r$, and $n_r$ are particle diameter, ring diameter, and number of particle per ring, respectively. If center of a ring $i$ is $(x_{ci}, y_{ci}, z_{ci})$ then position of particle $j$ the ring $i$ is

$$\tag{2} x_{ij} = x_o + d_r \cos \theta_{ij}, $$

$$\tag{3} y_{ij} = x_o + d_r \sin \theta_{ij}, $$

$$\tag{4} z_{ij} = z_o + i d_p \cos \tfrac16 \pi $$

$$\tag{5} \theta_{ij} = \tfrac12 (i-1) \Delta \theta + (j-1) \Delta \theta, $$

$$\tag{6} \Delta \theta = \frac{2\pi}{n_j}, $$

with $j = 1, 2, .., n_j$ and $i = 1, 2, .., n_i$.

notes

  • Sphere transparency can be tuned using alpha property 4.
  • Slider is one type of input 5.
