nuclear data model v1-json

  • Sparisoma Viridi
10 Aug 2026 · 2 mins read · edit

As continuation of an idea 1, nuclear data model is chosen as the first topic in learning nuclear reaction as discussed 2, where the format is JSON since it can be used in Python and JavaScript [^gpt_56_luna_2026b]. In this stage the model can already supply sufficient information to calculate the reaction Q-value (the net energy released or required) for a nuclear reaction 3.

exercises

  • Learn about JSON syntax and explain it in 2-3 short paragraphs.
  • Using a simple example show how to create and access it in a programming language, e.g. JavaScript or Python.
  • Create NUCLEAR_CONSTANTS object and show how to access the values.
  • Create list of atoms, using previous given JSON example, that contains at least five different atoms.
  • Show how to access an atom with certain isotope.
  • Create a presentation for the anwser, save it as PDF, share it on OSF, and submit URL of the file.
