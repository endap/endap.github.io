Each student has unique combination of datasets.

usage

  • Prepare a blank DOCX file as answer sheet.
  • Use the student ID, a 8-digit number, as seed to get the datasets.
  • Select seed according to the student ID.
  • Notice that datasets name and link appear.
  • Take screenshot of the app showing datasets name and link.
  • Insert the screenshot to the answer sheet. (point 5)
  • Click each link and open in a new browser tab.
  • Confirm dataset name as post title in all tabs.
  • Notice the meaning of dataset name, e.g. dataset g82s9 means $g = 82$ and $s = 9$.
  • Notice that each dataset consists of independent variable $x$ and dependent variable $y$.
  • Change id of points to find the best peak, last, initial and final points linear regression.
  • Notice the model used is $y = mx + b$.
  • Calculate values of $m$ and $b$.
  • Create table to summerize 10 values of peak, last, $m$, $b$ as function of $g$. (point 10)
  • Create xy-scatter chart for the values as function of $g$. (point 5)
  • Put table and chart in result and discussions part. (point 5)
  • Make analysis and explain in general what $x$, $y$, and $g$ might be. (point 10)
  • Discuss the process with your colleagues, if necessary.
  • Assure that you process your datasets.
  • Write references and AI chats that you use in creating the analysis. (point 10)
  • Declare the use of AI in the answer sheet. (point 5)
  • Assure that you include methodology, e.g. how to use the app, model, etc. (point 10)
  • Include flowchart how you process and analyize the datasets. (point 10)
  • Put your name, student ID, midterm date in the beginning of the answer sheet. (point 5)
  • Save the answer sheet as PDF. (point 5)
  • Upload the PDF file to assigned GitHub issue for the midterm. (point 5)
  • Notice the submission deadline. (point 5)
  • Create introduction part explaining what the datasets all about. (point 5)
  • Create summaries or conclusions explaining your findings. (point 5)
