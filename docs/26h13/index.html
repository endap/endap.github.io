equations

Position of agent $i+1$ is always in the front of agent $i$ since the system is using only single lane, which already common in traffic simulation 1, even it seems simple. Presented equations 2 are given in this section, which must be later confirmed to assure the notations and details compared to the work refereed 3.

At time $t$ distance in front of a vehicle (or agent) $i$ is calculated using

$$\tag{1} d_{\rm front} = x_{i+1}(t) - x_i(t) $$

and there is check distance

$$\tag{2} d_{\rm check} = l + v_i(t) \Delta t. $$

that determines how the next velocity to be calculated

$$\tag{3} v_i(t + \Delta t) = \left\{ \begin{matrix} {\rm min} (v_i(t) + a \Delta t, v_{\rm max}), & d_{\rm front} > d_{\rm check}, \newline \newline v_{i + 1}(t) - b \Delta t, & d_{\rm front} \le d_{\rm check}, \end{matrix} \right. $$

with $v_{\rm max}$ is maximum velocity, $a$ is acceleration, $b$ is deceleration, and $l$ is length, for all vehicles.

Next step is to update position of the agent

$$\tag{4} x_i(t + \Delta t) = x_i(t) + v_i (t + \Delta t) $$

using previous equation.

In the NetLogo following values

$$\tag{5} l = 1, \ \ \ \ \Delta t = 1 $$

are used, where the terms are patch and tick, respectively.

intialization

The road has length $L$ and periodic boundary condition, where vehicles position $x \in [0,1]$, which are generated using uniform distribution

$$\tag{6} \mathbf{X} \sim \mathcal{U}(a, b)^n, $$

with $a = 0$, $b = L$, and $n$ is number of vehicles. Since spatial distance is already discretized with $l$ then road length is defined as

$$\tag{7} L = ml, $$

where $m > n$.
